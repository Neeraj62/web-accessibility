# Web Accessibility 🌐

A practical repository for learning and implementing **Web Accessibility** using HTML, CSS,  JavaScript, ARIA, and WCAG best practices.

## 📚 Topics Covered

* Semantic HTML
* Accessibility Basics
* ARIA (Accessible Rich Internet Applications)
* Keyboard Navigation
* Screen Reader Support
* Accessible Forms
* Focus Management
* Color & Contrast
* Alt Text and Images
* Accessible Buttons & Links
* WCAG Guidelines
* Common Accessibility Issues
* Practical Examples

## 🎯 Goal

The goal of this repository is to understand how to build websites that are **accessible, usable, and inclusive for everyone**, including people using assistive technologies.

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* ARIA
* WCAG
